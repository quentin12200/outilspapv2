INSTALLATION COMPLÈTE
═══════════════════════════════════════════════════

# 1. Cloner ou créer la structure
git clone [URL_SI_GIT] mon_projet_tableau_bord_ud
# OU créer manuellement avec les commandes ci-dessus

# 2. Placer tous les fichiers

# 3. Installer Python (si pas déjà fait)
python --version  # Vérifier >= 3.8

# 4. Installer les dépendances
cd mon_projet_tableau_bord_ud/scripts
pip install -r requirements.txt

# 5. Tester l'installation
python ud_automation.py --help

# 6. Créer votre premier tableau
python ud_automation.py create --ud 66 --nom "Pyrénées-Orientales" --output ../data/TDB_UD66_2025.xlsx

# 7. Si utilisation Git
cd ..
git init
git add .
git commit -m "Initial commit - Template UD"

UTILISATION QUOTIDIENNE
═══════════════════════════════════════════════════

# Générer un rapport
cd scripts
python ud_automation.py rapport --fichier ../data/TABLEAU_de_BORD_UD66.xlsx --output ../exports/rapports/rapport_$(date +%Y%m%d).md

# Exporter vers JSON
python ud_automation.py export --fichier ../data/TABLEAU_de_BORD_UD66.xlsx --feuille "A CIBLE" --output ../exports/json/a_cible_$(date +%Y%m%d).json

# Valider les données
python ud_automation.py validate --fichier ../data/TABLEAU_de_BORD_UD66.xlsx 2>&1 | tee ../logs/validation_$(date +%Y%m%d).log

# Synchroniser Dashboard
python ud_automation.py sync-dashboard --fichier ../data/TABLEAU_de_BORD_UD66.xlsx --ud-code ud66 --api-url https://app.pap-cse.org/api

SAUVEGARDE DES DONNÉES
═══════════════════════════════════════════════════

Les données réelles ne sont pas sur Git, donc :

1. Sauvegarde locale régulière :
   - Copie manuelle sur disque externe
   - Ou script automatique

2. Sauvegarde cloud (si autorisé) :
   - Google Drive UD
   - Nextcloud
   - Synology
   - ⚠️ Chiffrer si cloud public !

3. Script de backup :

#!/bin/bash
# backup_data.sh
DATE=$(date +%Y%m%d)
BACKUP_DIR="/chemin/vers/backup"
mkdir -p "$BACKUP_DIR"
cp -r data/ "$BACKUP_DIR/data_$DATE/"
tar -czf "$BACKUP_DIR/backup_ud66_$DATE.tar.gz" -C "$BACKUP_DIR" "data_$DATE"
echo "Backup créé : backup_ud66_$DATE.tar.gz"

PARTAGE AVEC D'AUTRES UD
═══════════════════════════════════════════════════

Pour partager le template avec une autre UD :

1. Cloner uniquement le repo Git :
   git clone [URL_REPO] nouveau_projet_ud34
   
2. L'autre UD obtient :
   ✅ Toute la documentation
   ✅ Scripts d'automatisation
   ✅ Templates vides
   ✅ Structure de dossiers
   ❌ Aucune donnée de l'UD 66 (sécurité)

3. L'autre UD crée son propre tableau :
   cd scripts
   python ud_automation.py create --ud 34 --nom "Hérault"
